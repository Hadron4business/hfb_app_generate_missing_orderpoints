Generate Missing Reordering Rules

One click creates a min/max reordering rule for every stocked product that has none.

The problem

Products without a reordering rule never show up in Odoo's replenishment report, so nobody notices when they run low. Creating the rules one by one for hundreds of products takes hours, and new products are easy to forget.

What you get

Bulk creation

A rule for every storable product that has none, in one step.

You choose where

Pick the warehouse and the location the rules apply to.

Your own limits

Set the minimum and maximum quantity for the new rules (0 / 0 by default).

Category filter

Optionally limit the run to one product category and its subcategories.

Nothing overwritten

Products that already have a rule are skipped. See the count before you generate.

Review the result

After generating you land on the list of the new rules, ready to adjust.

How to use it

1
Open Inventory > Operations > Generate Missing Reordering Rules (needs the Inventory Administrator role).
2
Choose the Warehouse. The Location defaults to its stock location; change it if needed.
3
Optionally pick a Product Category, and set the Minimum and Maximum Quantity for the new rules.
4
Choose which products to skip: those that have a rule in any location (default), or only those with a rule in the chosen location.
5
Check Products to Receive a Rule - it shows how many rules will be created - and press Generate.
6
The new rules open in a list. Adjust min/max per product there, or use Inventory > Operations > Replenishment.

Good to know

  • Only storable products are considered (Track Inventory ticked).
  • Rules are created with the standard trigger of Odoo (automatic).
  • Archived rules count as existing rules, so a product whose rule you archived is not given a new one.
  • Running it again is safe: it only adds rules for products that still have none.
